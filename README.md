# Ventra-EMS — release channel

The Home Assistant add-on repository of Ventra-EMS (Ventra-tech Energy Management System).

## Installing

1. In Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ → Repositories** and add
   `https://github.com/frank8the9tank/ventra-ems-release`.
2. **Add-on Store → ⋮ → Registries**: add the registry login you received from Ventra-tech
   (registry `ghcr.io`, your username and token). The add-on's image is only available with it.
3. Install **Ventra-EMS** from the store.

This repository holds only the add-on's manifest and changelog; it is updated automatically with every release.
